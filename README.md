هذا المستودع مخصص لملف APK النهائي فقط. كود التطبيق محفوظ في مستودع خاص ولا يُنشر هنا.

- التثبيت يتم عبر نافذة أندرويد الرسمية.
- لا يبدأ تثبيت أي تطبيق دون موافقة المستخدم.
- لا يطلب المثبّت صلاحية الوصول الشامل إلى ملفات الهاتف.
